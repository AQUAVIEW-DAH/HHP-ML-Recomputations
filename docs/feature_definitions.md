# Feature reference: exact definitions, computation and statistics

Generated by `OHC/build_feature_definitions.py`. Covers the **37** features across the two recommended recipes: **34** for TCHP (`global_pruned_plus_neighborhood`) and **35** for D26 (`drop_both_lat_interactions_plus_neighborhood`). D26 drops the SSH x |lat| and temperature-excess x |lat| interactions and adds three deep-profile features.

## How the statistics were computed

* **Population:** the rows the model trains and is scored on, from the rebuilt tables of 2026-09-24: both Argo and RTOFS have 26 C water, one primary profile per Argo cast. **81,183** rows (of 322,616 collocated).
* **Missing values** are replaced by the training-fold median before fitting. `% imputed` is the share of this population where the feature is missing; `coverage (all rows)` is availability across all collocated rows, including cold water.
* **Mode:** exact for discrete features. For continuous features the centre of the tallest of 100 histogram bins between the 1st and 99th percentiles is reported instead, since the literal mode of a continuous variable is an arbitrary repeated value.
* **Range** is given twice: the 1st-99th percentile (the robust range) and the absolute min-max.

## The targets (for context: these are not inputs)

* **Argo TCHP and D26** (`hhp_core.compute_tchp_teos`, pressure axis): D26 is the first depth where temperature falls to 26 C, linearly interpolated between profile levels (depth from `gsw.z_from_p`). TCHP is the trapezoidal integral from the surface to D26 of rho * cp * max(T - 26, 0), with rho and cp from TEOS-10 at each level, converted to kJ/cm^2 (x 1e-7).
* **What the model predicts** is the error delta = Argo - RTOFS for each quantity. The corrected forecast is RTOFS + predicted delta.

### Raw model state

#### `model_interp_tchp_kj_per_cm2`  (kJ/cm^2)

* **Definition:** RTOFS Tropical Cyclone Heat Potential at the profile position: heat above the 26 C isotherm.
* **Computed:** Daily field: TCHP = 1e-7 * sum over HYCOM layers above D26 of rho * cp * max(T - 26, 0) * dz_eff, with rho = gsw.rho_t_exact(SA, T, p) and cp = gsw.cp_t_exact(SA, T, p) (TEOS-10), layer thickness = HYCOM thickness (Pa) / 9806, dz_eff the full layer if it lies above D26 or the part above D26 if it straddles it. Source: rtofs_glo.t00z.f06.archv (00Z cycle, 6-h forecast). Then sampled to the Argo position by inverse-distance-squared weighting over the 8 nearest RTOFS grid cells: F = sum(w_i F_i) / sum(w_i), w_i = 1/d_i^2, missing neighbours excluded. NaN where the column never reaches 26 C.
* **Code:** `build_rtofs_global_daily_tchp_fields.py (~L103-160); collocation in build_rtofs_at_argo_points_multiyear.py`
* **Statistics:** mean 51.79, std 41.45, median 42.06, quartiles 18.82 to 76.18, 1st-99th pct 0.1197 to 171.2, min 3.45e-05, max 277; mode 0.9751 (modal bin (continuous)); 81,183 valid, 0.0% imputed, 29.8% coverage across all rows.

#### `model_interp_d26_m`  (m)

* **Definition:** RTOFS depth of the 26 C isotherm at the profile position.
* **Computed:** Daily field: first HYCOM layer (from the surface) with T <= 26 C, linearly interpolated between that layer's centre depth and the one above: D26 = z1 + (T1 - 26)/(T1 - T2) * (z2 - z1). Requires the top layer to be >= 26 C. Then sampled to the Argo position by inverse-distance-squared weighting over the 8 nearest RTOFS grid cells: F = sum(w_i F_i) / sum(w_i), w_i = 1/d_i^2, missing neighbours excluded.
* **Code:** `build_rtofs_global_daily_tchp_fields.py (~L118-134)`
* **Statistics:** mean 65.96, std 31.42, median 63.7, quartiles 42.47 to 86.78, 1st-99th pct 5.318 to 145, min 0.5022, max 199.5; mode 64.69 (modal bin (continuous)); 81,183 valid, 0.0% imputed, 29.8% coverage across all rows.
